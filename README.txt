NOMAD SOWPON - LIVE DESKTOP WALLPAPER

FILES
- index.html: wallpaper structure
- style.css: visual styling and responsive layout
- script.js: live clock, date, randomized quotes, floating particles, cursor attraction

HOW TO RUN
1. Keep all three files in the same folder.
2. Double-click index.html to preview in your browser.
3. For Lively Wallpaper, choose Add Wallpaper > Browse and select index.html (or drag index.html into Lively).

CUSTOMIZE
- Change the displayed name in index.html: "Nomad Sowpon".
- Edit/add quotes in the quotes array in script.js.
- Quotes rotate randomly every 30 minutes.
- Background colors are in style.css under body.

NOTE
The Google Fonts import uses an internet connection. If offline, the wallpaper falls back to system fonts.
